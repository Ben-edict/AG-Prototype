# AG Print Studio — interactive prototype

A frontend-only React + TypeScript prototype built with Vite. AG is the company name provided for this concept. Service photography, project examples, contact information and enquiry records are illustrative placeholders.

## Preview locally

1. Install Node.js 20.19+ or 22.12+.
2. Open this folder in a terminal and run npm install.
3. Run npm run dev.
4. Open the local address printed in the terminal, usually http://localhost:5173.

To create a production build, run npm run build. To preview that build, run npm run preview.

## What's in the prototype

- Home, About, Services, service detail pages, project gallery, Contact and FAQ
- Digital and offset print, large format, stationery, flyers and magazines, apparel, mugs, packaging and labels, graphic design, invitations and event programmes, books, lamination, stickers, signage and document services
- Quote request form with optional artwork selection and a session-only confirmation
- Local admin preview with service visibility controls and quotation status updates
- Responsive glassmorphism styling, service filters, gallery filters and project lightbox

The prototype showcases services and collects quotation requests. It has no cart, checkout or payment features. Enquiry form submissions and admin changes are held only in frontend memory for the current browser session. Nothing is emailed or saved to a backend. The supplied book, merchandise, large-format and print-production photos are bundled locally in `public/images`; additional sample photography loads from Unsplash and needs an internet connection. Replace the sample contact details, service content and gallery items before launch.
